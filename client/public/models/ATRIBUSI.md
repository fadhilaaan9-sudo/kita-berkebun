# Atribusi Asset — Balapan Kita (prototipe)

Semua asset 3D di `client/public/models/` berasal dari **Kenney** (https://kenney.nl),
lisensi **CC0 1.0** (bebas dipakai pribadi & komersial, atribusi tidak wajib
tapi disarankan — file ini adalah atribusinya).

## Kit yang dipakai

- **Kenney Toy Car Kit** → `kenney_toy-car-kit/`
  https://kenney.nl/assets/toy-car-kit
  Mobil (vehicle-*.glb), lintasan mainan (track-*.glb), gerbang start/finis
  (gate.glb, gate-finish.glb), item (item-*.glb: pisang, box, koin, cone),
  penyangga (supports-*.glb). Termasuk `Textures/colormap.png`.

- **Kenney City Kit: Roads** → `kenney_city-kit-roads/`
  https://kenney.nl/assets/city-kit-roads
  Potongan jalan kota (road-*.glb), jembatan, properti (construction-*,
  light-*, electricity-*). Termasuk `Textures/colormap.png`.

## Catatan

- Asset pertanian dari fase sebelumnya (tanaman, hewan, karakter, pagar)
  sudah dihapus dari branch ini.
- File `.glb` di-commit langsung di branch `racing/prototype` (prototipe).
