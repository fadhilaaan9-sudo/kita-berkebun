# Aset 3D — Kebun Kita

Semua model di folder ini **CC0 (public domain)** dari [Kenney](https://kenney.nl):
bebas dipakai untuk proyek pribadi maupun komersial, tanpa atribusi wajib.

> **Catatan:** file `.glb`/tekstur tidak di-commit ke git. Setelah `git clone`
> atau `git pull`, jalankan sekali dari root repo:
>
> ```bash
> ./scripts/fetch-models.sh            # Linux / macOS / Git Bash / WSL
> ```
>
> ```powershell
> powershell -ExecutionPolicy Bypass -File scripts\fetch-models.ps1   # Windows
> ```
>
> Script mengunduh ulang file-file di bawah ini dari kenney.nl.

| File | Sumber | Isi |
|---|---|---|
| `crops_dirtSingle.glb` | [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) | Petak tanah (tilled) |
| `crops_wheatStageA.glb` / `crops_wheatStageB.glb` | Kenney Nature Kit | Gandum muda / matang |
| `crops_leafsStageA.glb` / `crops_leafsStageB.glb` | Kenney Nature Kit | Wortel muda / matang |
| `crops_cornStageB.glb` / `crops_cornStageD.glb` | Kenney Nature Kit | Labu muda / matang |
| `fence_simple.glb` | Kenney Nature Kit | Pagar kebun |
| `animal-cow.glb` | [Kenney Cube Pets](https://kenney.nl/assets/cube-pets) | Sapi (animasi: idle, walk, eat, ...) |
| `animal-chick.glb` | Kenney Cube Pets | Ayam (animasi: idle, walk, eat, ...) |
| `character-a.glb` (+ `Textures/texture-a.png`) | [Kenney Blocky Characters](https://kenney.nl/assets/blocky-characters) | Avatar pemain (animasi: idle, walk, ...) |
